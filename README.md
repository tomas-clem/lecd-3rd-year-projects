# Data Science & Engineering — 3rd Year Projects

Selected projects from the third year of my degree in Data Science and Engineering (*Licenciatura em Engenharia e Ciência de Dados*) at the University of Coimbra (FCTUC), academic year 2023/24.

| Project | What it does | Stack |
|---|---|---|
| [House price prediction platform](house-price-prediction-platform/) | Web platform that estimates the price of a house in Portugal from its characteristics, with favourites, price history and a price map | Python, Flask, scikit-learn, AWS DynamoDB, Plotly |
| [Facial emotion recognition](facial-emotion-recognition/) | Feature engineering on facial landmark videos to classify 8 emotions | Python, NumPy, SciPy, scikit-learn |
| [Movie Bayesian network](movie-bayesian-network/) | Bayesian network learned from IMDB movie data to reason about budget, revenue, score and genre | Python, pandas, pgmpy |
| [Data visualization](data-visualization/) | Two visualization projects: metal bands by country, and a COVID-19 dashboard | Python, Plotly, Dash |
| [Museum IoT monitoring](museum-iot-monitoring/) | Simulated sensors for 5 museum rooms, processed in real time over MQTT and stored in InfluxDB | Python, MQTT, InfluxDB, Grafana, Raspberry Pi |
| [Patient manager in C](patient-manager-c/) | Command-line manager for a doctor's patients and clinical records, built on linked lists | C, CMake |

All projects except the first data visualization project were group work; each README credits the other members.
